# AI Sales Prospecting Agent

An AI-powered B2B sales prospecting agent that analyzes LinkedIn company data, detects niches, identifies buying signals, scores leads, and helps sales teams focus on high-quality prospects.

## Features

* LinkedIn company enrichment using Apify
* AI-powered niche detection using Ollama (Llama 3)
* Lead scoring engine
* Staffing/recruitment agency detection
* Buying signal detection
* FastAPI backend
* React frontend

## Tech Stack

* FastAPI
* React
* Apify
* Ollama
* Llama 3
* Python
